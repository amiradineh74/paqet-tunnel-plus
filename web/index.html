مدیریت سرویس انتخاب‌شده

عملیات زیر فقط سرویس تعیین‌شده را کنترل می‌کند؛ تغییر تنظیمات و فایروال انجام نمی‌شود. هر عمل در تاریخچه سرور ثبت می‌شود.

هشدار: توقف یا ری‌استارت ممکن است ارتباط کاربران آن تانل را موقتاً قطع کند.

تست سرعت واقعی از درون تانل

برخلاف دانلود مستقیم اینترنت روی سرور، این تست باید از Client ایران وارد تونل و از Server آلمان خارج شود؛ هم دانلود، هم آپلود و هم تأخیر بررسی شوند.

فرق تست‌ها

بنر SSH: تأیید عبور یک اتصال کوتاه و واقعی از تونل.

تست Ping بیرونی: ارزیابی شبکه عمومی سرور؛ الزاماً مسیر Paqet نیست.

تست Through-Tunnel: ترافیک واقعی از داخل مسیر انتخابی با محدودیت حجم و زمان.

KCP: تحلیل کیفیت و رفتار انتقال، نه صرفاً فعال بودن سرویس.

لاگ سرویس انتخاب‌شده

برای مشاهده لاگ واقعی، ابتدا پنل روی سرور اجرا شود، سپس با توکن وارد شوید. این بخش هیچ دستور اجرایی روی سرویس اجرا نمی‌کند.

دسترسی امن به پنل

نسخه قابل اجرای نمونه، فقط روی 127.0.0.1:8792 گوش می‌دهد و API آن با توکن محافظت شده است. برای باز کردن در مرورگر رایانه شخصی، از تونل SSH محلی استفاده می‌شود؛ هیچ پورت مدیریتی عمومی باز نمی‌شود.

ssh -L 8792:127.0.0.1:8792 root@SERVER_IP
